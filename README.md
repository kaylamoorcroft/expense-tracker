# Expense Tracker

## Overview
This program allows users to keep record of expenses (transactions) and monitor finances.
## Features
Load File
    read in previously saved data from a csv file

Save File
    save changes made during program execution to a specified file 

Add Transactions
    add individual transactions to spreadshee: based on date, amount, and category 

Delete Transactions
    remove a transaction from file/spreadsheet

Edit Transactions
    update an exisiting transaction; may change the date, amount, or category

Get transactions from date
    retrieve and display the data of a specified transaction from file/spreadsheet

Display Spreadsheet
    show all transactions found within a file/spreadsheet

Get stats
    display statistics for a specified month of transactions; show total income, total expense, cashflow, and category with the highest expenses
## Usage
```
make
Main
```
